# 邮件职位推荐→JD核实→简历定制流程

> 最后更新: 2026-06-22
> 来源: 求职流程执行经验

## 流程概述

从Gmail职位推荐邮件中提取岗位 → L1关键词粗筛 → L2邮件摘要核实 → L3全文JD核实 → 9维度评估 → 简历定制 → 投递

## 详细步骤

### Step 1: 提取岗位（L1粗筛）
1. 运行 `gmail-job scan` 或手动扫描Gmail
2. 从LinkedIn/JobsDB/Glassdoor/Indeed邮件中提取岗位信息
3. 按关键词初筛评分（仅参考，不作为结论）

### Step 2: 邮件摘要核实（L2）
1. 读取推荐邮件的完整内容
2. 提取公司名、岗位名、地点、薪资（如有）
3. 基于摘要判断是否值得进一步核实
4. 标注状态：⚠️L2已核实

### Step 3: 全文JD核实（L3）
1. 从邮件中提取LinkedIn/JobsDB岗位链接
2. 用 `browser_navigate` 打开岗位页面抓取完整JD
3. 如果页面需要登录，尝试curl或用户手动打开
4. 保存JD到 `JD库/` 目录（必须包含中文翻译）

### Step 4: 9维度匹配评估
1. 基于用户画像进行9维度评估
2. 核心三维（行业+职能+技能）单独算分
3. 综合分 = 核心三维 + 辅助维度
4. 核心三维<5/9的岗位不列为强推

### Step 5: 简历定制
1. 从V3 base简历复制
2. 修改求职目标（中英文）
3. 修改个人优势（中英文）
4. 保存为 `你的简历_V3-{公司简称}-{岗位方向}.docx`

### Step 6: 更新追踪表
1. 更新 `投递追踪.md` 中的岗位池状态
2. 更新 `~/.hermes/job-search/application_tracker.json`
3. 标注状态：📄简历已定制 或 📝待投递

## 关键规则

1. **L1结果禁止使用"强推""值得投"等措辞** — 必须完成L3核实后才能推荐
2. **推荐前必须查重投递追踪表** — 避免推荐已投递/已枪毙的岗位
3. **明显需要做的步骤直接执行** — 不要问用户"要不要继续"
4. **已投递岗位从岗位池移除** — 岗位池只保留待投/观望的岗位
5. **JD文件必须包含中文翻译** — 方便用户快速阅读决策
